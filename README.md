# limen-dev/homebrew-tap

Homebrew formulae for [Limen](https://github.com/limen-dev/limen).

```sh
brew install limen-dev/tap/limen
```

There is no formula yet. `Formula/limen.rb` will be written by Limen's release workflow once releases are public, pointing at the release's macOS and Linux archives and their SHA-256 checksums. Don't edit formulae here by hand.
